# NEXA RPG

Novo projeto independente de RPG 2D/2.5D para web, desktop e mobile.

## Direção inicial

- Phaser + TypeScript + Vite
- Mundo 2D/2.5D com pixel art detalhada, iluminação e profundidade
- Primeiro vertical slice: mapa, Kael, câmera, movimentação, criaturas, combate e drops
- Mobile e desktop desde a base
- O projeto NEXA anterior permanece separado

> Nome provisório: NEXA RPG. A identidade final será definida durante o desenvolvimento.
